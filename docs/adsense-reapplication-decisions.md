## 1. Executive Summary & Methodology

This document records the page-by-page triage and diversion decisions (`Keep` vs. `301 Redirect`) for all **73 indexable URLs** in `sitemap.xml` on `https://www.yuliusbox.com`, based on three verified evidence sources collected on **2026-11-05**:

1. **Google Search Console (GSC) URL Inspection Census (`gsc-census-20261105.json`)**:
   - **58 URLs**: `Submitted and indexed` (`verdict: PASS`, `pageFetchState: SUCCESSFUL`).
   - **13 URLs**: `Discovered - currently not indexed` (`lastCrawlTime: null` — discovered via sitemap/internal links, never fetched by Googlebot due to low crawl budget on a ~115 weekly PV site).
   - **1 URL**: `Crawled - currently not indexed` (`/tools/word-to-pdf`, `lastCrawlTime: 2026-10-21T14:16:36Z`).
   - **1 URL**: `URL is unknown to Google` (`/tools/video-to-gif/video-to-gif-for-discord`, `lastCrawlTime: null`).
2. **AdSense Site Auditor Content Depth Baseline (`audit-text-depth-20261105.txt`)**:
   - All 73 sitemap URLs pass the `>= 300` main-content word bar (`72 PASS` at `>= 450` words; `1 note` on `/contact` at `404` main-content words, which is a trust/contact page).
3. **AdSense Site Auditor Duplication Baseline (`audit-duplicates-20261105.txt`) & Pairwise Shingle Analysis**:
   - `check_duplicates.py` (5-word shingle Jaccard similarity across all 73 URLs at threshold `0.6`) returned **`[PASS] ADS-CONTENT-02 (part) 73 URLs — no near-duplicate groups`**.
   - Direct pairwise 5-word shingle Jaccard similarity between every unindexed variant page and its parent hub page ranges from **`0.0000` (0.00%) to `0.0134` (1.34%)**, confirming that every scenario page carries independent editorial copy, distinct H2 structure, dedicated FAQs, and functional tool presets rather than keyword-swapped boilerplate.

| Field | Verified Data & Analysis |

| **GSC Status** | `Crawled - currently not indexed` (`lastCrawlTime: 2026-10-21T14:16:36Z`, `pageFetchState: SUCCESSFUL`, `indexingState: INDEXING_ALLOWED`) |

| **Overlap Audit vs. `/tools/pdf-kit`** | **1. Functional Overlap = 0%**: `/tools/pdf-kit` is a 100% client-side PDF manipulation tool (`pdf-lib` + `PDF.js`) supporting 5 modes on existing PDFs and JPG images (`Merge PDF`, `Compress PDF`, `Split PDF`, `Extract Pages`, `JPG to PDF`). It **cannot** parse or convert Microsoft Word `.doc` (OLE2 binary) or `.docx` (Office Open XML) files. Conversely, `/tools/word-to-pdf` converts `.doc` and `.docx` documents to PDF via an isolated stateless LibreOffice/Gotenberg container endpoint (`/api/tools/word-to-pdf`), matching its three indexed siblings (`/tools/excel-to-pdf`, `/tools/ppt-to-pdf`, `/tools/url-to-pdf`).<br>**2. Content Overlap = 0.00%**: 5-word shingle Jaccard similarity between `/tools/word-to-pdf` and `/tools/pdf-kit` is `0.0000`.<br>**3. Soft-404 Risk of Redirecting**: A 301 redirect from `/tools/word-to-pdf` to `/tools/pdf-kit` would send users with `.doc`/`.docx` files to an uploader that only accepts `.pdf` and `.jpg` files, creating a textbook Soft 404. |
| **Decision** | **Keep (Retain) + Content Deepening & Consistency Fix** |
| **Rationale & Remediation Applied** | Inspection of `/tools/word-to-pdf` revealed two concrete quality issues that explain why Googlebot crawled the page on 2026-10-21 without indexing it:<br>1. **Client/Server Copy Contradiction**: `WordToPdfClient.tsx` displayed `Max 50MB` and `3 per minute` rate limit, contradicting both the server-rendered prose in `src/app/tools/word-to-pdf/page.tsx` and the actual API route `src/app/api/tools/word-to-pdf/route.ts` (`MAX_FILE_SIZE = 30 MB`, `Ratelimit.slidingWindow(5, "1 m")`), and appended a repetitive 2-paragraph boilerplate block below the main `ToolSeoBody`.<br>2. **Depth of Technical Guidance**: While `page.tsx` had 2 intro sections, it lacked technical depth on how headless LibreOffice handles OpenXML `.docx` vs. legacy `.doc` files, font metric substitution on Linux containers, and pagination behavior.<br>**Fixes Applied**: Synchronized `WordToPdfClient.tsx` to `30 MB` and `5 requests per minute`, removed the redundant client-side boilerplate footer inside `WordToPdfClient.tsx`, expanded `src/app/tools/word-to-pdf/page.tsx` with 4 comprehensive technical sections (headless LibreOffice/Gotenberg pipeline, font metric equivalence for Calibri/Cambria/Times New Roman vs. Carlito/Caladea/Liberation, table/page-break preparation, and post-conversion local PDF workflows), and added strong internal links from `/`, `/tools`, and `/tools/pdf-kit`. |
